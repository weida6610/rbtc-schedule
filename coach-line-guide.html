RBTC 教練預約系統

請提供你的 LINE ID 與加好友連結

預約系統準備在學員送出預約後，直接顯示對應教練的 LINE 聯絡方式。 這樣即使學員沒有開啟「允許以 LINE ID 加入好友」，也可以由學員主動加入教練，減少聯繫失敗。

請回傳 4 個項目
  • 教練姓名
  • LINE ID
  • LINE 加好友連結
  • 2 張截圖：LINE ID 頁面、加好友連結頁面

一、找到 LINE ID

請在自己的 LINE 個人檔案裡確認 ID，並回傳文字與截圖。

  1. 1 打開 LINE進入「主頁」或「我的」頁面。
  2. 2 點右上角設定進入「個人檔案」。
  3. 3 找到 ID 欄位把 LINE ID 複製或手動打出來。

二、取得加好友連結

我們最需要的是「加好友連結」，之後會做成學員可直接點擊的按鈕。

  1. 1 打開 LINE 主頁點「加入好友」或「好友」相關入口。
  2. 2 進入邀請或 QR Code找到「分享連結」、「複製連結」或「邀請連結」。
  3. 3 複製連結通常會長得像 https://line.me/ti/p/...。

三、截圖說明

請回傳下面兩張截圖，方便我們確認資料正確，避免連結放錯或 ID 少打一個字。

截圖 1
LINE ID 畫面

請截到「個人檔案」裡顯示 LINE ID 的畫面。若畫面有電話、Email 或其他私人資料，可以先遮掉， 但請保留 LINE ID 清楚可見。

截圖 2
加好友連結或 QR Code 畫面

請截到可以看到「分享連結 / 複製連結 / QR Code」的畫面。若可以，請同時把連結文字貼給我們， 不要只傳 QR Code 截圖，這樣比較不會輸入錯。

小提醒：請不要只傳 LINE 顯示名稱。顯示名稱會重複，也不一定能加好友；我們需要 LINE ID 與加好友連結。

四、請直接照這個格式回傳

複製下面格式，填完後連同兩張截圖一起傳回來。

教練姓名： LINE ID： LINE 加好友連結： 已附上： 1. LINE ID 截圖 2. 加好友連結或 QR Code 截圖

常見問題

如果我找不到加好友連結怎麼辦？

先回傳 LINE ID 與 QR Code 截圖，我們可以協助確認。不過最理想還是提供可點擊的加好友連結。

為什麼學員要主動加教練？

有些學員沒有開啟「允許以 ID 加入好友」，教練可能加不到學員。改成學員送出預約後主動加入教練，成功率會比較高。

我的 LINE ID 需要公開在預約前嗎？

不會。規劃上會在學員送出預約後，才顯示該預約教練的聯絡方式。
